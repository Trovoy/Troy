## 导入前

1. 阅读对应客户端说明，并先以文本方式检查配置。
2. 备份现有配置，按自己的环境修改策略组、订阅和远程资源。
3. 在目标客户端的当前版本中校验，再替换可用配置；旧第三方链接不保证仍有效。

本仓库不提供订阅、代理服务器或客户端许可证；已归档规则不再宣称持续维护或自动更新。
