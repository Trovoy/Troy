# Troy's Proxy Configurations

Personal Loon, Surge and Clash configuration examples, supporting resources and app icons.

**Maintenance is paused.** These files are retained for reference and may contain outdated syntax, URLs or third-party integrations. This is a configuration collection, not the active [GitHub profile repository](https://github.com/Trovoy/Trovoy).

## Before importing

1. Read the relevant client README and inspect its configuration as text.
2. Back up your current configuration and adapt policy groups, subscriptions and remote resources to your own environment.
3. Validate it in the target client's current version before replacing working settings. Do not assume an old third-party URL is still available.

No subscriptions, proxy servers or client licenses are supplied. The archived rulesets are not advertised as current or automatically maintained.
